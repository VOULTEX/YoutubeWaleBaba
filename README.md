# YouTube Wale Baba
Static site (HTML/CSS/JS). Host on GitHub Pages: push files to a repo > Settings > Pages > Deploy from branch (main, / root).
- The photo is embedded directly in `index.html` (base64). To change it, replace the long `data:image/jpeg;base64,...` value in the `<img src>`.
- Change WhatsApp number/message in `script.js`.
